# godot-dungeon-crawler-fps

A first-person action prototype in **Godot 4.7.1**. Rigged first-person arms, one
looted weapon, parkour movement, a horde enemy and a hand-placed guard enemy, in
two levels: a Halloween-dusk arena and a Post Void style corridor crawl.

You start with two empty fists and there is one attack on one button. Left click
swings; hold it and it keeps swinging. The dagger is chest loot, and taking it
only changes what the swing is.

## Running

Godot 4.7.1, with **Jolt** as the physics engine. Both are what the project is
built against; older 4.x will not open it correctly.

```bash
godot --editor --path .          # open the editor
godot --path .                   # run the arena (scenes/main.tscn)
godot --path . scenes/corridors.tscn   # run the corridor level
```

Levels are **generated by re-runnable scripts** rather than hand-built, so layout
is reproducible. Each loads the base scene, strips the nodes it owns, rebuilds,
and saves:

```bash
godot --headless --path . -s tools/build_terrain.gd     # writes scenes/main.tscn
godot --headless --path . -s tools/build_corridors.gd   # writes scenes/corridors.tscn
```

## Controls

| Input | Action |
|---|---|
| WASD | move |
| Shift | sprint |
| Space | jump; while wall running, kick off the wall |
| Mouse | look |
| Left click | attack — hold to keep swinging |
| E | interact — open a chest, lift a gate, take a pickup |
| Escape | release the mouse |

Wall running engages automatically: be airborne, moving fast enough, and
alongside a near-vertical surface.

## Documentation

**[`DESIGN.md`](DESIGN.md)** is the real documentation — every script, the scene
structure, the level generators, and the engine behaviour that has already cost
debugging time (what `PackedScene.pack()` silently drops, why skinned meshes
report useless AABBs, why a `PhysicalBone3D` inverts its skeleton's scale). Read
it before changing anything.

`tools/` also holds a set of `_`-prefixed throwaway probes. They are kept because
the numbers they print are the only defence against re-guessing measurements that
were expensive to get right — clip boundaries in a baked animation take, doorway
sizes read off geometry, per-chunk UV windows on smashed props.

## Assets

**The sky panorama is not in this repository.** `pumpkin_mountain_2160.png`, an
equirectangular sunset panorama by **psychopom**, is free to use but may not be
redistributed. To get the arena looking as intended, obtain it and place it at:

```
assets/sky/pumpkin_mountain_2160.png
```

then re-run `tools/build_terrain.gd`. Without it the build still works —
`_build_sky_and_sun()` falls back to a procedural dusk sky and prints a warning —
but the lighting rig was tuned against the panorama, including the sun yaw, which
was measured from where its glow actually sits.

Other third-party content in `assets/`, by pack:

| Path | What |
|---|---|
| `textures/` | Screaming Brain Studios Horror Texture Pack — **CC0** |
| `hands/` | `arms_rig.glb`, a 52-bone two-arm viewmodel rig with 18 clips |
| `dungeon/` | PSX dungeon kit, 43 FBX plus atlases |
| `chonchon/`, `watcher/`, `creature/`, `retro_character/`, `skeleton/` | character models |
| `chest/`, `dagger/` | props |
| `fonts/m5x7.ttf` | pixel font by Daniel Linssen |

Only the texture pack's licence (CC0) and the sky panorama's restriction are
documented in this project. **The remaining packs ship without licence files and
their terms have not been verified here** — check each one against its original
source before reusing this repository's contents or redistributing it.
